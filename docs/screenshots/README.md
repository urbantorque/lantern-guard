# Gameplay gallery

These six unedited browser screenshots show the current game at a 480 × 960 portrait viewport. They were captured from real, deterministic Standard runs on Millpond, Reed Crossing and Stone Weir. Tower costs, enemy health and resources were not altered for the images.

To recreate the scenes, run `npm run qa:gallery`, open `/qa/` on the development server, then use the six **Gameplay gallery** buttons. The QA page backs up the previous save and mutes audio. Resume the scene, let the return message clear, then capture gameplay or open the relevant tower/route panel. Use **Restore earlier test data** afterwards.
